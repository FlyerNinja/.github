## How we work

- **One-command dev environment.** Every engineer bootstraps the whole ecosystem from a single repo; a terminal UI drives git and Docker across the workspace.
- **GitOps all the way down.** Infrastructure as code (OpenTofu + Ansible), stack descriptors in git, encrypted secrets, Docker Swarm on OVH — staging and production.
- **Event-driven services.** NATS between domains, centralised identity (Zitadel), a shared API gateway.

**Stack:** TypeScript · NestJS · Python · FastAPI · PHP · Laravel · Vue · PostgreSQL · NATS · Docker Swarm · OpenTofu · Zitadel

## Why this org looks empty

Our code is proprietary and our repositories are private — what you see here is the storefront, not the warehouse. Occasionally we open-source something small and self-contained.
