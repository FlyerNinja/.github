<h1 align="center">FlyerNinja 🥷</h1>
<p align="center">Retail promotions, digitised — flyers, conversational commerce and in-store signage for Italian grocery retail.</p>

---

## What we build

| | |
|---|---|
| 📄 **Flyer platform** | Retailers' paper flyers become structured, searchable, shoppable digital flyers — ingestion, editorial tooling, rendering and a consumer viewer. |
| 💬 **Conversational commerce** | A WhatsApp Business platform for retail: campaigns, catalogues, loyalty and customer care at national scale. |
| 📺 **Digital signage** | In-store video and radio networks, scheduled and measured centrally. |
| 📊 **Analytics** | One measurement layer across flyer, chat and in-store — what shoppers actually look at. |

## Stack

TypeScript · NestJS · Python · FastAPI · PHP · Laravel · Vue · PostgreSQL · NATS · Docker Swarm · OpenTofu · Zitadel
